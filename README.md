# 螢幕錄影工具 Pro (Screenrecorder - 超長時錄影防崩潰強化版)

本工具為免安裝的純前端網頁應用程式，直接在瀏覽器中進行高畫質的螢幕錄影與混合錄音。採用最新 **IndexedDB 磁碟快取串流**、**硬碟空間自動偵測與守護** 與 **純螢幕 Zero-Copy 直通架構**，徹底解決傳統網頁錄影「長時間錄製導致記憶體耗盡 (OOM) 閃退」、「硬碟空間不足導致檔案損毀」、「切換視窗背景節流畫面凍結」以及「WebM 影片無法拖動進度條」等核心缺陷。

## 🌟 核心特色

1. **100% 本地端運行 (Local Only)**：純前端實作，不依賴任何後端伺服器，您的錄影檔案與畫面絕對不會外流，確保最高等級的隱私安全。
2. **硬碟空間自動偵測與守護 (Disk Space Guardian)**：
   - 啟動前自動呼叫 Storage Estimate API 估算可用剩餘磁碟空間與預估可錄製時長。
   - 錄影期間每 10 秒即時輪詢，若剩餘空間降至極限（< 150MB），系統會**自動安全結束並保存已錄製內容**，防止硬碟爆滿造成影片損壞。
3. **突破網頁記憶體極限 (IndexedDB 磁碟快取)**：錄影區塊每秒直接寫入瀏覽器沙盒磁碟，記憶體佔用恆定維持在數十 MB，支援數小時甚至更長的長時間會議與教學錄製，告別記憶體崩潰（Aw, Snap! / Out of Memory）。
4. **背景切換不凍結 (Zero-Copy & Background Guard)**：
   - 純螢幕模式下直接採用硬體直通串流，切換到其他軟體或最小化時完全不受瀏覽器 `requestAnimationFrame` 節流影響。
   - 子母畫面模式下內建背景定時保全計時器，確保畫布持續合成不卡死。
5. **完整進度條支援 (WebM EBML Duration Patch)**：內建純前端 EBML 時間軸標頭修復，導出的影片在 Chrome、Edge、VLC、QuickTime 等播放器皆可正常顯示總時間與隨意快進倒退。
6. **意外崩潰還原 (Crash Recovery)**：即使錄影中途不慎關閉分頁或瀏覽器異常重啟，重新開啟網頁時會自動提示「發現未完成紀錄」，可一鍵還原下載。

## 🛠 詳細功能與介紹

### 1. 多元畫面擷取模式 (Display Surface Mode)
* **整個螢幕桌面**：錄製整個電腦畫面（推薦，視野最完整）。
* **特定應用程式視窗**：僅錄製某個被打開的軟體畫面（例如 PowerPoint 簡報），保護其他視窗隱私。
* **特定瀏覽器分頁**：僅錄製當前瀏覽器中的某個指定分頁。

### 2. 畫質與碼率模式選擇
* **標準高畫質 (5 Mbps)**：兼具清晰度與流暢度，適合一般教學與操作示範。
* **長時節能省空間 (2.5 Mbps)**：適合數小時的線上會議、演講、長時間監控錄影，檔案體積極致輕量。
* **極致原畫細節 (8 Mbps)**：適合遊戲動態、高精細設計展示。

### 3. 硬碟剩餘空間與時長換算
* 即時顯示本機硬碟可用 GB 與可錄製總時長。
* 切換不同畫質模式時自動連動換算。
* 提供綠色（充足）、黃色（偏低）、紅色（危急）狀態標籤與進度條指示。

### 4. 專業級雙軌混音
* **錄製系統聲音**：能夠側錄電腦本身發出的聲音（如背景音樂、會議中的其他人的聲音）。
* **錄製麥克風**：錄下旁白解說，內建迴音消除與雜音抑制。
* 若僅勾選單一音訊源，系統自動啟用直通模式以節省資源；同時勾選時自動啟動 Web Audio 混音並具備背景保活。

### 5. 可拖曳子母畫面攝影機 (PiP Camera)
* 開啟網路攝影機（Webcam）後，即時人像以「子母畫面」浮動於預覽區。
* 支援**滑鼠 / 觸控自由拖曳**，可隨意移至不遮擋簡報重點的位置。

## ⚠️ 使用須知 (Usage Notices)

1. **Mac 系統聲音錄製說明**：由於 macOS 系統隱私權限制，瀏覽器擷取「整個螢幕」時預設無法直接錄取全域系統音訊（僅分頁支援音訊共用）。若需在 Mac 錄製全系統聲音，可搭配如 BlackHole 等虛擬音訊驅動程式。
2. **瀏覽器支援度**：建議使用最新版 Google Chrome、Microsoft Edge、Brave 或 Firefox 電腦版以獲得最佳硬體編碼與 Storage Estimate 支援。手機與平板因作業系統限制不支援網頁螢幕擷取。

## 🚀 如何使用

1. 使用 Google Chrome 或 Microsoft Edge 開啟目錄下的 `index.html`（或線上網址）。
2. 設定錄製偏好（模式、碼率、音訊與攝影機開關），並檢視硬碟剩餘空間與可錄時長。
3. 點擊「開始擷取與錄製」，並於瀏覽器彈窗中選取欲共用的畫面。
4. 錄製期間可隨時點擊「暫停」或「結束」，系統會即時守護硬碟空間。
5. 點擊「結束錄影」後，系統將自動修復時間軸並提供預覽回放與「下載影片檔」。
